DART corp_code lookup with caching (from 02-RESEARCH.md Pattern 2):
```python
CORP_CODE_URL = "https://opendart.fss.or.kr/api/corpCode.xml"
CORP_CODE_CACHE = os.path.join(PROJECT_ROOT, "data", "raw", "dart", "corp_code_map.csv")

def get_corp_code_map(api_key):
    if os.path.exists(CORP_CODE_CACHE):
        df = pd.read_csv(CORP_CODE_CACHE, dtype=str)
        return dict(zip(df["stock_code"], df["corp_code"]))
    r = requests.get(CORP_CODE_URL, params={"crtfc_key": api_key}, timeout=60)
    r.raise_for_status()
    z = zipfile.ZipFile(io.BytesIO(r.content))
    xml_data = z.read("CORPCODE.xml")
    root = ET.fromstring(xml_data)
    rows = []
    for item in root.findall("list"):
        code = item.findtext("corp_code", "").strip()
        stock = item.findtext("stock_code", "").strip()
        name = item.findtext("corp_name", "").strip()
        if stock:
            rows.append({"stock_code": stock, "corp_code": code, "corp_name": name})
    df = pd.DataFrame(rows)
    df.to_csv(CORP_CODE_CACHE, index=False)
    return dict(zip(df["stock_code"], df["corp_code"]))
```

DART hyslrSttus per-firm pull (from 02-RESEARCH.md Pattern 3):
```python
def pull_hyslr_shareholder(corp_code, api_key):
    time.sleep(0.5)
    r = requests.get(
        "https://opendart.fss.or.kr/api/hyslrSttus.json",
        params={"crtfc_key": api_key, "corp_code": corp_code,
                "bsns_year": "2023", "reprt_code": "11011"},
        timeout=20,
    )
    r.raise_for_status()
    data = r.json()
    if data.get("status") != "000":
        return None, None
    rows = data.get("list", [])
    common = [row for row in rows if row.get("stock_knd") == "보통주"]
    if not common:
        common = rows
    largest_rows = [r for r in common if r.get("relate") == "최대주주 본인"]
    group_rows = [r for r in common if r.get("relate") in ("최대주주 본인", "최대주주의 특수관계인")]
    def sum_pct(rows):
        total = 0.0
        for row in rows:
            try:
                total += float(row.get("trmend_posesn_stock_qota_rt", 0) or 0)
            except (ValueError, TypeError):
                pass
        return total if total > 0 else None
    return sum_pct(largest_rows), sum_pct(group_rows)
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .env → script | FSS_API_KEY loaded from .env; must not appear in logs or stdout |
| DART API response → DataFrame | JSON fields are strings; numeric parsing must be wrapped in try/except |
| corpCode.xml download → local cache | ZIP response parsed in memory; malformed ZIP must raise, not silently corrupt cache |
| universe_raw.csv → ticker list | File may be absent or missing ticker column; validated at script entry |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | FSS_API_KEY in logs | mitigate | Key read into variable; never interpolated into log.info/log.debug strings; only passed as function argument |
| T-02-02 | Information Disclosure | FSS_API_KEY in stdout | mitigate | "No DART match" stdout report prints only ticker list, never the key |
| T-02-03 | Denial of Service | DART API rate limiting (429) | mitigate | 0.5s sleep between per-firm calls; requests.HTTPError caught and logged; script continues |
| T-02-04 | Tampering | Malformed DART JSON response | mitigate | `data.get("status") != "000"` check before accessing "list"; float() try/except on percentage field |
| T-02-05 | Tampering | Malformed corpCode.xml ZIP | mitigate | `r.raise_for_status()` before ZipFile parse; exception propagates and halts script (fail-safe) |
| T-02-06 | Elevation of Privilege | Path traversal in output path | accept | Output path is constructed from PROJECT_ROOT constant; no user-supplied path components |
</threat_model>
